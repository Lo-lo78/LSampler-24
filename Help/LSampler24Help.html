LSampler-24 0.99.25: accessible guide

TEST176 — Import selected REAPER items directly

Select one or more audio items in REAPER, open the LSampler-24 Slot grid, choose the starting slot and press Alt+V. No Ctrl+C, SWS or Lua is required. Simple source trims are preserved even for multiple items cut from the same source file. Selected items load in timeline order. Every item maps Low Key, High Key and Original Pitch to the same consecutive MIDI note, starting with 60 (C4). Occupied slots ask before replacement. If no items are selected, the previous clipboard/SWS and internal slot-paste features remain available. Stretch, reversed items, changed playrate/pitch, section sources and items looped beyond their source are skipped rather than imported incorrectly; FX, fades and envelopes are not rendered.

New in TEST170 — deterministic Free LFO restart on DAW Play

Whenever REAPER or another compatible DAW starts playback, LFO 1 and LFO 2 with Trigger Off (Free) restart from a known phase. This applies to per-slot Mono and per-voice Poly, including repeatable Sample & Hold, Smooth, Delay and Free One Shot. Triggered LFOs and sample playback, envelopes and effects are unchanged; no new parameter or preset change. Free still runs at its selected frequency, not continuously tied to the song timeline.

Historical TEST169 — paste SWS audio source paths (fallback)

In REAPER on Windows, select audio items and run the existing action SWS/BR: Copy take media source file path of selected items to clipboard (_BR_TSOURCE_PATH_TO_CLIPBOARD). In LSampler-24 choose the starting Slot and press Alt+V. One complete source file per clipboard line is imported consecutively until Slot 24. No Lua required; existing slot copy/paste and other DAWs are unchanged. The original Ctrl+C copies REAPER items, NOT audio file paths. Trimmed items import as complete files: render first to include item FX, fades, pitch or stretch.

New in TEST168 — REAPER-only copy of audio items into Slots

Historical TEST168 note: the native REAPER Ctrl+C item-clipboard reader is experimental. For current direct imports, select items and use Alt+V as described in TEST176 above.

New in 0.99.25 — de-click transitions and Sample Window bounds

Mono retrigger and Poly voice replacement now overlap the outgoing and incoming audio for 3 ms, without using additional musical voices. With Legato On and Portamento Off, a one-millisecond pitch transition keeps the sample read-head moving without restarting its envelope. Ordinary note attacks and the Main Loop do not change. In Sample Window, Sample End cannot move below Sample Start, and Sample Start cannot move above Sample End. These limits work with keyboard arrows and typed Value input, including screen-reader feedback.

New in 0.99.24 — 4 November 2026: LReaParams-style search

The parameter search now matches the behavior of LReaParams 0.0.63: type a prefix in less than 1 second; Shift+letter or Shift+digit searches backwards. Matches are found at the beginning of a parameter name or at the beginning of any word within it, with full-name matches preferred. A repeated character cycles matches. Search is Unicode-aware, and 0 still finds Zero Crossing while Z searches for its name. The prior 1.2-second behavior described below applies only to TEST164.

New in 0.99.23 — 4 November 2026: incremental keyboard parameter search

In a parameter Grid, type consecutive letters or digits to find the beginning of the displayed and spoken parameter name: for example, type M then I to find MIDI Channel. A single character cycles matching parameters forward; repeat that character to continue cycling. Shift+character searches backward; notably, Shift+1 searches for the digit 1, not the typed symbol !. The prefix is cleared after 1.2 seconds of inactivity or by using navigation keys, switching Grid/Value or changing pages. The search wraps within the current parameter view. 0 still reaches Zero Crossing. Applies to Slot/Global Grid, Bank Macro, Slice Editor parameter pages, FX Grid and Sample Set F2; browser and numeric entry remain unchanged.

New in 0.99.22 — 4 November 2026: per-slot MIDI channels

Each of the 24 Slots has a new MIDI Channel setting in the Slot parameter category, immediately after Slot Polyphony. Select Omni (default, receives MIDI notes on all 16 channels) or 1 through 16. For example: Slot 1 = 5 and Slot 2 = 8; notes on channel 5 play Slot 1, notes on channel 8 play Slot 2. Multiple Slots can share the same channel for layering. A specific channel still respects Low/High Key, Velocity Low/High, Sample Sets, and Slice MIDI Map. Note Off, sustain, all-notes/all-sound-off and pitch bend continue to follow the MIDI channel of each playing voice. MIDI Channel is saved with Slot presets, Bank presets and REAPER projects, and exposed to host automation. Preview buttons remain independent of MIDI input routing. Older presets without this setting use Omni, retaining their previous layering behavior; this routing does not create extra voices or DSP engines.

LSampler-24 is a 24-slot sampler. Each slot can hold a single sample or a Sample Set of up to 16 samples. The main editor, parameter grid, Sample Set editor, browsers and Slice editor are designed for keyboard use and screen readers.

New in 0.99.21 — 27 October 2026: LFO modulation

Each slot has two independent LFO pages, LFO 1 and LFO 2. New LFO 1 Voice Mode and LFO 2 Voice Mode settings offer Mono and Poly (default). Poly preserves the original independent LFO phase for each playing voice. Mono shares one oscillator among all active voices in the same slot, independently of the other 23 slots. In Mono, a new note with Trigger enabled restarts the shared oscillator and therefore affects other held notes in that slot. The two LFOs can use different modes. Voice Mode does not replace the independent Free/Trigger or One Shot options.

Seven additional parameters are available for each LFO: One Shot Percent (0–100%, fraction of a cycle before holding when One Shot is enabled; 0 repeats), Phase (0–1, waveform phase offset), Env Rate (−10 to +10, the slot's amplifier envelope modulates LFO speed), Square PWM (0.05–0.95, square-wave pulse width), Upper Squash and Lower Squash (0–1, independently reduce the positive and negative parts), and Cross Rate (−40 to +40, frequency modulation by the other LFO). Cross Rate also works when the two LFOs use different voice modes.

To edit these controls, open a loaded slot's parameter Grid and navigate to its LFO 1 or LFO 2 page. Use Grid/Value shortcuts as described below. The default Poly mode and neutral defaults of the other controls preserve the earlier sound; settings are retained in Slot and Bank presets and are available for host automation.

Main slot page

Arrow keys move through the 24 slots in the 3-by-8 grid. Ctrl+Home and Ctrl+End jump to the first and last slot. Enter opens the selected slot parameters. Alt+Enter opens Properties. Alt+R renames the slot. Alt+C copies, Alt+X cuts and Alt+V pastes a slot. Delete clears the current slot; Alt+Delete clears the bank. Alt+P toggles slot audition mode; when enabled, moving between slots auditions the selected slot with Space assigned to preview rather than the DAW.

The action buttons are Load Sample, Load Slot, Save Slot, Load Bank, Save Bank, Help and About. Tab/Shift+Tab move between focusable controls. Arrow, Home, End, Page Up and Page Down are consumed while a main action button has focus, so they do not escape from the plug-in. Alt+L goes directly to the main parameter grid from a button or the Slot page. Alt+H opens the Help language menu and Alt+A opens About.

Loading, saving and library

Alt+O opens the sample import browser. Alt+S opens the Slot library, Alt+B opens the Bank library. Alt+Shift+S and Alt+Shift+B open Save Slot and Save Bank: enter a filename (the current filename is prefilled), press Enter, then use the internal browser to select a folder inside Slots or Banks. Enter saves in the current folder, including the root; Right enters a highlighted subfolder, Left/Backspace returns to its parent, Escape cancels. In Slot and Bank browsers, Shift+F10 opens New Folder / Rename Element / Delete Element, F2 renames the selected file or folder and Delete asks for Y/N confirmation. In regular load browsers, Enter loads the selected file.

Parameter grid

Enter on a non-empty slot opens its parameter grid. Arrow keys navigate the grid. Left/Right changes parameter category/page while preserving the row. Alt+Shift+Left/Right changes category/page and selects its first parameter. Type the beginning of the parameter name announced by the Grid (for example M then I for MIDI Channel); repeated initials cycle matches and Shift+character searches backwards, including digits. Alt+Up/Down changes the value; in the Loops category Alt+Shift+Up/Down changes the active subloop (1–10), while Shift+arrows navigates active DAW automation parameters; Alt+Page Up/Down changes it by the coarse step; Alt+Left/Right chooses the step width; Alt+Home/End goes to the parameter maximum/minimum. Alt+V moves to Value editing. Enter in the manual value editor commits and returns to the grid. Escape leaves the parameter editor and returns to the slot page. Ctrl+Left/Right scrubs Sample Play Start. Alt+L returns focus to the main parameter grid; Alt+Shift+L toggles the main loop through Main Playback Mode. Alt+G opens/closes Global parameters. Alt+P switches the grid between sample preview and DAW Space behaviour.

DAW automation

Version 0.99.21 exposes the sampler's meaningful musical and DSP controls to the VST3 host as thousands of independent automation parameters, including additional loop, bank and FX controls. Parameters are addressed directly by their real Slot and function, for example “Slot 1 - Volume” or “Slot 2 - Filter Cutoff”; automation does not follow the currently selected Slot. Changes made from the Grid/Value interface notify the host, and automation played by the DAW updates the same internal parameters and DSP. File loading, browser commands, Help/About, focus, destructive editing and other non-musical actions are intentionally not automation parameters.

Sample Set

Alt+M opens the Sample Set editor for the current slot. A slot may contain up to 16 samples. Tab/Shift+Tab switch between the sample list and the Sample Set parameter grid. In the sample list, Up/Down select the sample, Enter loads/replaces it, Delete removes it and Space auditions it. In the parameter grid, Up/Down move between parameters, Left/Right move between columns, Alt+Up/Down edit values, Alt+Page Up/Down make coarse changes, Alt+Left/Right select the global edit step, and Enter or Alt+V switches between Grid and Value. Current parameters include Velocity Low, Velocity High and Variation Mode; variation choices include Off, Round Robin, Random, Random No Repeat and Shuffle No Repeat. Shuffle plays every eligible sample once per cycle, in a random order, without repeating the same sample at a cycle boundary.

Ten Subloops: Repeat Level, Release and Crossfade (TEST128)

Each subloop has Loop Level (-120 to +24 dB; 0 dB is unity; -120 dB mutes its output). Level applies to that subloop's first pass and all its repeats, with a short anti-click smoothing ramp. The global Repeat After Note Off switch decides whether subloop repeats continue after MIDI Note Off; it does not switch off the amp envelope's release. Loop Crossfade (0 to 200 ms) now blends the outgoing end of a repeat into its next start, including subloops marked One Shot, provided another repeat will actually happen. The already-blended start is not replayed at the wrap. Since TEST130 each subloop has its own Loop Crossfade; the former global control has been removed from the grid. The Main Loop no longer uses this crossfade. Crossfade is bypassed with Stretch, Ping Pong and fixed-time pitched repeats when the read head does not follow the virtual clock.

Independent subloop processors (TEST130)

Each of the ten subloops now has Loop Crossfade (0–200 ms), Loop RAM Downsample (0–100%), Loop Pan (-100..100), Repeat Level Amount (-24..+24 dB per repeat) and Loop Direction (Forward / Reverse / Ping Pong). At RAM Downsample 0, playback inherits the slot's RAM Downsample. Above zero, that subloop progressively lowers both the virtual sample frequency (source rate down to 8 kHz) and bit resolution (16 to 4 effective bits). It does not shrink the source in RAM. Repeat Level Amount is cumulative per repeat but clamped to -120..+24 dB and smoothed. Loop Pan combines with slot Pan and Repeat Pan. Ping Pong alternates reading direction at each repeat without changing the main transport; crossfade is disabled in Ping Pong to avoid phase-invalid blending. The retired slot-level Loop Crossfade is left internally for old VST3 parameter identities but has no DSP effect.

Loop Repeat Pan and Pitch Step Time (TEST126)

In the Loops page, each of the ten subloops has Repeat Pan (-100 to +100) and Loop Pitch Step Time. Positive Repeat Pan sweeps from left to right across its repeats; negative reverses direction, exactly like Slice Repeat Pan. With infinite repeats, pan travels back and forth in a long 256-pass cycle. Loop Pitch Step Time has Original Pitch Loop (keeps the repeat duration measured at zero repeat pitch, with a virtual clock) and Pitch Resizes Loop (repeat duration follows pitch). Original Pitch Loop is the default for new subloops. In original-time mode, pitching a repeat up can leave a silent remainder; pitching down can truncate the read before reaching its end, matching the Slice fixed-step design. Each main-loop restart re-arms the ten subloops.

Slice editor

In automatic Slice Mode (Reverse, Pendulum, Random, Random No Repeat, Center Out and Edges In), the ten subloops may play inside each selected source slice. Their Start/End coordinates always refer to the original sample; only the part inside the current source slice is available. Repetitions complete before the slice advances, so a slice can take longer. Slice Mode Off retains normal subloop playback; Slice Sequencer and single-slice auditions remain independent and never trigger subloops.

Alt+E opens Slice Edit for the current sample. F1 selects Global Slice Settings; F2/F3 select Sequencer or Boundaries when Slice Mode permits them. Tab moves through available pages. The arrow keys, Home and End navigate the active page. Alt+Up/Down edits the current value, Alt+Page Up/Down makes coarse changes, Alt+Left/Right changes the edit step and Alt+Home/End selects maximum/minimum. Enter allows typed values. Space toggles normal preview; when preview is off, slice and step navigation can auto-audition. Escape closes the Slice editor. Stretch Amount and Stretch Frequency use overlap-add smoothing inside the current slice and respect Reverse.

Updated full reference — TEST139

Keyboard, focus and parameter search

The sampler has 24 slots, each with up to 16 samples (384 sample positions per bank), and a shared 96-voice pool. Alt+E opens Slice Editor, Alt+M opens Sample Set, Alt+H opens Help, and Alt+A opens About. In the parameter Grid, Up/Down changes the selected row; Left/Right changes page keeping the corresponding row; Alt+Shift+Left/Right changes page and selects its first item. Home/End selects the category ends, Page Up/Down moves eight items, and Ctrl+Home/End moves to the grid bounds. Type one or more characters of the displayed parameter name to narrow the search; repeat a single character to cycle forward or hold Shift to search backwards. The digit 0 searches for Zero Crossing; numbers are not positional parameter shortcuts. Function keys must not trigger letter-search inadvertently. Alt+V switches to Value; Escape backs out. Sample preview stops on leaving the Grid.

Sample editing and Zero Crossing

Sample Play Start/End define the usable sample range; Loop Start/End define loop points. Ctrl+Left/Right scrubs Sample Play Start. Search for Zero Crossing with 0 and activate with Enter after selecting endpoints. The operation searches near the selected endpoints (up to 40 ms / 4096 samples), comparing multi-channel levels and loop-junction continuity; it cannot guarantee a transparent loop and does not generate a loop automatically. Save the Slot after editing. Main Playback Mode governs main-loop versus one-shot playback; Alt+Shift+L toggles it in the Grid.

Sample Set and variations

Alt+M provides F1 Samples (16 positions), F2 Sample Parameters (per-position Velocity Low/High), and F3 Global Parameters (slot-wide Variation Mode). Tab/Shift+Tab moves between pages; Ctrl+Up/Down changes sample on F2/F3 only. Variation modes: Off, Round Robin, Random, Random No Repeat and Shuffle No Repeat. The Sample browser previews the raw WAV without slot processing. Loading over an occupied sample needs confirmation.

Slice and the ten independent subloops

Alt+E opens Slice Edit, with page availability dependent on the active Slice Mode. Automatic modes include Reverse, Pendulum, Random, Random No Repeat, Center Out and Edges In. Subloops may play within the intersecting part of the current source slice; their repeats complete before the next slice. Slice Sequencer, isolated-slice previews and Slice Bypass never trigger those subloops. Stretch Amount/Frequency use smoothed, slice-bounded crossfading.

The Loops page offers ten independent subloops, enabled by changing their respective settings, with Loop Level (-120 to +24 dB), per-repeat Level Amount (-24 to +24 dB), per-loop Crossfade (0–200 ms), RAM Downsample (0–100%), Loop Pan and Repeat Pan (-100 to +100), and Direction (Forward, Reverse, Ping Pong). Crossfade is bypassed in incompatible playback modes. The main loop rearms all subloops on restart. Original Pitch Loop preserves repeat-clock duration; Pitch Resizes Loop follows pitch. Repeat After Note Off controls repeated loops without disabling the amplifier ADSR release.

Bank Macro, DAW automation and library

Alt+K opens Bank Macro. Relative mode (Alt+U) addresses an automatable parameter; Set All writes individual Slot controls and is not a separately automatable macro. Ctrl+Shift+A attempts to activate/deactivate automation for the selected parameter. Alt+Shift+A deactivates every active REAPER automation envelope for this LSampler-24 instance without deleting recorded points; NVDA announces the number deactivated or says none were active. REAPER integration toggles ACTIVE, VISIBLE and ARM, preserving envelope points; NVDA appends “Auto” when active. Other hosts are limited by their VST3 integration. Alt+O imports samples, Alt+S browses Slots, Alt+B browses Banks, and Alt+Shift+S/B saves them. The Advanced menu supports file, folder, bank and whole-library import/export. Portable .lsampler-24.ls24 packages contain necessary WAV files; banks use .lsampler-24-b. Browser commands include Shift+F10, F2 and Delete; file operations are asynchronous.

TEST151: FX Gate and Delay Sync

Alt+F: Delay Sync uses Off (milliseconds) or 1/32, 1/24, 1/16, 1/12, 1/8, 1/6, 1/4 note lengths from the host BPM. Both Delay Speed L/R multiply that duration. Delay Resonance L/R (0–100%) follows the respective Tone control, default 0. Separate Delay Level L/R (-infinity to 0 dB) precede the global Delay Gain. Reverb Gate Threshold is Off by default or -79 to 0 dB, and Gate Decay is 0–5000 ms; the gate opens immediately and closes with Decay, without Attack. Alt+F remembers its selected Grid parameter even when the DAW recreates the editor. These bank effects are not saved inside individual Slot presets.

Master FX — TEST145 (Alt+F)

The FX button or Alt+F opens the master stereo FX Grid from anywhere in the sampler. Alt+F does not close it: Escape returns Value to Grid, then Grid to the previous screen. Tab changes between Grid and Value; Alt+L focuses Grid, Alt+V focuses Value. Grid Up/Down navigates within one category, Left/Right changes FX groups, Page Up/Down navigates eight parameters, and Home/End moves to the category edges. Grid and Value have silent boundaries. Alt+Up/Down changes values, Alt+Left/Right selects the step (1, 5, 10, 15, 20), Alt+Page Up/Down changes coarsely, Alt+Home selects maximum and Alt+End minimum. In Value, the same editing works with unmodified arrows, Page Up/Down and Home/End. Backspace restores the default; Ctrl+Shift+A handles host automation. Chorus, Dual Delay and FX Master default to Off; Reverb Type also defaults Off. The three general Bank Chorus Send, Bank Delay Send and Bank Reverb Send controls are under Alt+K. Each Slot also has its own Bank Chorus Send, Bank Delay Send and Bank Reverb Send as the final three entries of its parameter grid. These 0–100% amounts independently feed the shared FX engines without changing the dry audio. The Alt+K values are bank-wide master send amounts; the effective level is the Slot send multiplied by its corresponding Bank send. The FX grid Alt+F sets the algorithms without changing those three send amounts. Save Slot (Alt+Shift+S) writes that Slot’s three Send amounts, but never the FX engine settings in Alt+F. Save Bank (Alt+Shift+B) writes all Slot sends, all Bank sends, and all FX engines. Loading a Slot does not change the Bank FX settings. Pre-TEST149 Slots using the main stereo output default to 100%; legacy Slots routed to separate output buses default to 0% to retain their previous FX routing. New Sends can route those slots to the main stereo FX return. REAPER project state also retains the FX settings. Reverb Decay goes from 0 to 20000 ms. Size, Damping, Early Reflections and Reverb Tail Tone now have independent and audible controls. Studio Room, Concert Hall, Plate and Cathedral use an eight-line stereo feedback network. FX are saved in projects and banks and affect the stereo master, not separately routed slot outputs.

Practical guidance

For multi-sampled pianos map the sample velocity ranges and keyboard zones; for drums verify one-shot playback and release; for sustained sounds tune loop endpoints, Zero Crossing and ADSR. Filters, LFOs, stretching and high polyphony increase CPU. Check and save banks before replacing existing content.

Dieci sottoloop: Volume, Release e Crossfade (TEST128)

Elaborazioni indipendenti dei sottoloop (TEST130)

Ognuno dei dieci sottoloop dispone di Loop Crossfade (0–200 ms), Loop RAM Downsample (0–100%), Loop Pan (da -100 a +100), Repeat Level Amount (da -24 a +24 dB per ripetizione) e Loop Direction (Forward / Reverse / Ping Pong). Con RAM Downsample a 0 viene ereditato il RAM Downsample dello slot. Sopra zero la frequenza virtuale scende progressivamente dalla frequenza del campione a 8 kHz e la risoluzione da 16 a 4 bit effettivi; non si riduce la memoria occupata. Repeat Level Amount varia a ogni ripetizione, con limite totale -120..+24 dB e rampa anti-click. Loop Pan si somma al Pan dello slot e al Repeat Pan. Ping Pong alterna la direzione audio a ogni ripetizione, senza cambiare il trasporto principale: il crossfade viene disabilitato in Ping Pong per evitare raccordi incoerenti. Il vecchio parametro globale Loop Crossfade resta soltanto come identificativo VST3 storico, ma non elabora più il suono.

Repeat Pan e Loop Pitch Step Time (TEST126)

Nella pagina Loops ciascuno dei dieci sottoloop dispone di Repeat Pan (da -100 a +100) e Loop Pitch Step Time. Un Repeat Pan positivo sposta progressivamente le ripetizioni da sinistra verso destra, quello negativo fa il contrario, come nello Slice. Con ripetizioni infinite il pan va e torna su un ciclo lungo 256 passaggi. Loop Pitch Step Time offre Original Pitch Loop, che mantiene costante la durata virtuale del loop a pitch di ripetizione zero, e Pitch Resizes Loop, nel quale la durata segue il pitch. Original Pitch Loop è la modalità predefinita per i nuovi sottoloop. Nella modalità Original Pitch Loop un pitch più acuto può lasciare silenzio in fondo alla ripetizione, mentre uno più grave può interrompere prima la lettura: è lo stesso criterio dello Slice a durata fissa. Ogni ripartenza del Main Loop riarma tutti i sottoloop.

0.99.23 の新機能 — 2026年11月4日：パラメーターのインクリメンタル検索

パラメーターの Grid では、読み上げられる名前の先頭文字を連続入力して検索できます。例：M に続けて I を押すと MIDI Channel が見つかります。同じキーの連打で次の候補へ進み、Shift+キー で逆方向へ検索します。Shift+1 は記号 ! ではなく数字 1 を検索します。1.2 秒の停止、矢印キー、ページやフォーカスの変更で検索文字列はリセットされます。0 は従来どおり Zero Crossing に対応します。Slot/Global、Bank Macro、Slice、FX、Sample Set F2 で利用できます。数値入力とブラウザーは変更されません。

24 個の Slot それぞれに MIDI Channel を追加しました。Slot カテゴリーの Slot Polyphony の直後にあります。Omni（初期値、全 16 チャンネルを受信）または 1–16 を選択できます。例：Slot 1 = 5、Slot 2 = 8。同じチャンネルを複数の Slot に設定してレイヤーにすることも可能です。キー範囲、ベロシティ範囲、Sample Sets、Slice MIDI Map は引き続き有効です。Note Off、サステイン、All Notes/Sound Off、ピッチベンドは各ボイスのチャンネルに従います。設定は Slot、Bank、REAPER プロジェクトに保存され、VST3 オートメーションにも対応します。Preview は MIDI 入力チャンネルと無関係です。旧プリセットは Omni で読み込まれ、DSP エンジンやボイスが自動的に増えることはありません。

0.99.21 の新機能 — 2026年10月27日：LFO モジュレーション

各スロットには独立した LFO 1 と LFO 2 ページがあります。新しい LFO 1 Voice Mode と LFO 2 Voice Mode は Mono または Poly（初期値）を選べます。Poly は従来どおり各ボイスで LFO の位相を独立させます。Mono は同じスロットの発音中のノートで1つの LFO を共有し、他の23スロットには影響しません。Trigger が有効な場合、新しいノートは共有 LFO を再始動し、保持中のノートにも影響します。2つの LFO は異なるモードに設定でき、Free/Trigger と One Shot もそれぞれ独立です。

各 LFO に7つのパラメーターが加わりました。One Shot Percent（0～100%、One Shot 時に停止する周期位置。0 は繰り返し）、Phase（0～1、位相オフセット）、Env Rate（−10～+10、AMP ADSR による LFO 速度変調）、Square PWM（0.05～0.95、矩形波のパルス幅）、Upper Squash と Lower Squash（0～1、正側と負側を個別に弱める）、Cross Rate（−40～+40、もう一方の LFO による周波数変調）。Mono と Poly を組み合わせても Cross Rate は機能します。

サンプルを読み込んだスロットのパラメーター Grid から LFO 1 または LFO 2 ページへ移動してください。初期値 Poly と他の中立値は従来の音を維持します。これらの設定は Slot/Bank プリセットに保存され、VST3 オートメーションからも制御できます。
