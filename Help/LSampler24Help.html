LSampler-24 0.99.11: accessible guide

LSampler-24 is a 24-slot sampler. Each slot can hold a single sample or a Sample Set of up to 16 samples. The main editor, parameter grid, Sample Set editor, browsers and Slice editor are designed for keyboard use and screen readers.

Main slot page

Arrow keys move through the 24 slots in the 3-by-8 grid. Ctrl+Home and Ctrl+End jump to the first and last slot. Enter opens the selected slot parameters. Alt+Enter opens Properties. Alt+R renames the slot. Alt+C copies, Alt+X cuts and Alt+V pastes a slot. Delete clears the current slot; Alt+Delete clears the bank. Alt+P toggles slot audition mode; when enabled, moving between slots auditions the selected slot with Space assigned to preview rather than the DAW.

The action buttons are Load Sample, Load Slot, Save Slot, Load Bank, Save Bank, Help and About. Tab/Shift+Tab move between focusable controls. Arrow, Home, End, Page Up and Page Down are consumed while a main action button has focus, so they do not escape from the plug-in. Alt+L returns from an action button to the current slot. Alt+H opens the Help language menu and Alt+A opens About.

Loading, saving and library

Alt+O opens the sample import browser. Alt+S opens the Slot library. Alt+Shift+S saves the current Slot. Alt+B opens the Bank library and Alt+Shift+B saves a Bank. Browser navigation supports the keyboard and preview facilities exposed by the current browser. Escape closes a browser without applying an unwanted selection.

Parameter grid

Enter on a non-empty slot opens its parameter grid. Arrow keys navigate the grid. Alt+Shift+Left/Right changes parameter category/page. Alt+Up/Down changes the value; Alt+Page Up/Down changes it by the coarse step; Alt+Left/Right chooses the step width; Alt+Home/End goes to the parameter maximum/minimum. Alt+V moves to Value editing. Enter in the manual value editor commits and returns to the grid. Escape leaves the parameter editor and returns to the slot page. Ctrl+Left/Right scrubs Sample Play Start. Alt+L toggles the main loop through Main Playback Mode. Alt+G opens/closes Global parameters. Alt+P switches the grid between sample preview and DAW Space behaviour.

DAW automation

Version 0.99.11 exposes the sampler's meaningful musical and DSP controls to the VST3 host as 6,629 independent automation parameters. Parameters are addressed directly by their real Slot and function, for example “Slot 1 - Volume” or “Slot 2 - Filter Cutoff”; automation does not follow the currently selected Slot. Changes made from the Grid/Value interface notify the host, and automation played by the DAW updates the same internal parameters and DSP. File loading, browser commands, Help/About, focus, destructive editing and other non-musical actions are intentionally not automation parameters.

Automazione DAW

La versione 0.99.11 espone alla DAW 6.629 parametri VST3 indipendenti per i controlli musicali e DSP che possono essere automatizzati. I parametri sono legati direttamente allo Slot e alla funzione reale, per esempio “Slot 1 - Volume” o “Slot 2 - Filter Cutoff”: l’automazione non segue lo Slot attualmente selezionato. Le modifiche eseguite da Grid/Value notificano l’host e l’automazione riprodotta dalla DAW aggiorna gli stessi parametri interni e il DSP. Caricamento file, browser, Help/About, focus, operazioni distruttive e altri comandi non musicali restano intenzionalmente fuori dall’automazione.

Sample Set

Alt+M opens the Sample Set editor for the current slot. A slot may contain up to 16 samples. Tab/Shift+Tab switch between the sample list and the Sample Set parameter grid. In the sample list, Up/Down select the sample, Enter loads/replaces it, Delete removes it and Space auditions it. In the parameter grid, Up/Down move between parameters, Left/Right move between columns, Alt+Up/Down edit values, Alt+Page Up/Down make coarse changes, Alt+Left/Right select the global edit step, and Enter or Alt+V switches between Grid and Value. Current parameters include Velocity Low, Velocity High and Variation Mode; variation choices include Off, Round Robin, Random, Random No Repeat and Shuffle No Repeat. Shuffle plays every eligible sample once per cycle, in a random order, without repeating the same sample at a cycle boundary.

Slice editor

Alt+E opens Slice Edit for the current sample. F1 selects Global Slice Settings; F2/F3 select Sequencer or Boundaries when Slice Mode permits them. Tab moves through available pages. The arrow keys, Home and End navigate the active page. Alt+Up/Down edits the current value, Alt+Page Up/Down makes coarse changes, Alt+Left/Right changes the edit step and Alt+Home/End selects maximum/minimum. Enter allows typed values. Space toggles normal preview; when preview is off, slice and step navigation can auto-audition. Escape closes the Slice editor. Stretch Amount and Stretch Frequency use overlap-add smoothing inside the current slice and respect Reverse.

About

Press Alt+A or activate the About button to open the accessible About panel. It reports LSampler-24 version 0.99.11, release date, project link and contact information. Escape or Alt+C closes About and returns focus to the previous control.

Help

Press Alt+H or activate the Help button. Choose a language from the accessible menu titled “Choose Help language”. The guide is embedded in the plug-in, written to a temporary HTML file and opened in the default browser. The language links at the top of this page can switch language again.

Pagina principale degli Slot

Le frecce si muovono tra i 24 Slot nella griglia 3 per 8. Ctrl+Home e Ctrl+End vanno al primo e all’ultimo Slot. Invio apre i parametri dello Slot selezionato. Alt+Invio apre Properties. Alt+P attiva o disattiva l’ascolto degli Slot: quando è attivo, spostarsi tra gli Slot ascolta quello selezionato e Spazio viene usato per l’anteprima invece che dalla DAW.

I pulsanti principali sono Load Sample, Load Slot, Save Slot, Load Bank, Save Bank, Help e About. Tab/Shift+Tab spostano il focus tra i controlli. Quando il focus è su uno di questi pulsanti, Frecce, Home, End, Page Up e Page Down vengono intercettati e non fanno uscire dal plugin. Alt+L ritorna dal pulsante allo Slot corrente. Alt+H apre il menu delle lingue dell’Help e Alt+A apre About.

Griglia parametri

Alt+Su/Giù modifica il valore; Alt+Page Up/Down usa il passo grossolano; Alt+Sinistra/Destra sceglie lo Step; Alt+Home/End va al massimo/minimo del parametro. Alt+V passa a Value. Invio nell’editor manuale conferma e torna alla griglia. Escape esce dai parametri e ritorna agli Slot. Ctrl+Sinistra/Destra effettua lo scrub di Sample Play Start. Alt+L attiva/disattiva il loop principale tramite Main Playback Mode. Alt+G apre/chiude i parametri Global. Alt+P alterna nella griglia l’anteprima del campione e lo Spazio della DAW.

Sample Set

Alt+M apre il Sample Set dello Slot corrente. Uno Slot può contenere fino a 16 campioni. Tab/Shift+Tab alternano tra elenco Sample e griglia parametri Sample Set. Nell’elenco, Su/Giù sceglie il campione, Invio lo carica o sostituisce, Delete lo rimuove e Spazio lo ascolta. Nella griglia, Su/Giù naviga i parametri, Sinistra/Destra cambia colonna, Alt+Su/Giù modifica i valori, Alt+Page Up/Down fa variazioni grossolane, Alt+Sinistra/Destra seleziona il passo globale ed Invio o Alt+V alterna Grid e Value. I parametri comprendono Velocity Low, Velocity High e Variation Mode; le modalità sono Off, Round Robin, Random, Random No Repeat e Shuffle No Repeat. Shuffle utilizza una volta tutti i campioni idonei per ogni ciclo, senza ripetizioni tra cicli.

Slice Editor

Alt+E apre Slice Edit sul campione corrente. F1 seleziona Global Slice Settings; F2/F3 selezionano Sequencer o Boundaries quando Slice Mode lo permette. Tab passa tra le pagine disponibili. Frecce, Home ed End navigano la pagina attiva. Alt+Su/Giù modifica il valore, Alt+Page Up/Down usa variazioni grossolane, Alt+Sinistra/Destra cambia il passo e Alt+Home/End imposta massimo/minimo. Invio permette di digitare il valore. Spazio attiva/disattiva l’anteprima normale; quando è disattivata, la navigazione di slice e step può produrre auto-audition. Escape chiude lo Slice Editor. Stretch Amount e Stretch Frequency usano una sovrapposizione con crossfade confinata alla slice corrente e rispettano Reverse.

About

Premi Alt+A oppure attiva il pulsante About per aprire il pannello About accessibile. Mostra LSampler-24 versione 0.99.11, data di rilascio, collegamento al progetto e contatto. Escape o Alt+C chiudono About e riportano il focus al controllo precedente.

LSampler-24 是一个 24 槽采样器。每个槽可包含一个采样，或最多 16 个采样的 Sample Set。主界面、参数网格、浏览器和 Slice Editor 均面向键盘与屏幕阅读器操作。

主槽页面

方向键在 24 个槽之间移动。Ctrl+Home/Ctrl+End 到第一个/最后一个槽。Enter 打开参数，Alt+Enter 打开 Properties。Alt+R 重命名；Alt+C 复制、Alt+X 剪切、Alt+V 粘贴。Delete 清除当前槽，Alt+Delete 清除整个 Bank。Alt+P 切换槽试听。

主要按钮为 Load Sample、Load Slot、Save Slot、Load Bank、Save Bank、Help 和 About。Tab/Shift+Tab 移动焦点。按钮获得焦点时，方向键、Home、End、Page Up、Page Down 会被插件拦截，不会把焦点带出插件。Alt+L 返回当前槽，Alt+H 打开帮助语言菜单，Alt+A 打开 About。

参数

Enter 打开参数网格。方向键导航；Alt+Shift+左/右切换分类；Alt+上/下调整数值；Alt+Page Up/Down 粗调；Alt+左/右选择步长；Alt+Home/End 到最大/最小。Alt+V 打开 Value。Escape 返回槽页面。Ctrl+左/右移动 Sample Play Start。Alt+L 切换主循环，Alt+G 打开 Global。

DAW 自动化

0.99.11 版本向 VST3 主机公开了 6,629 个独立的可自动化音乐与 DSP 参数。每个参数都直接对应真实的槽和功能，例如 “Slot 1 - Volume” 或 “Slot 2 - Filter Cutoff”；自动化不会跟随界面中当前选择的槽。通过 Grid/Value 进行的修改会通知主机，DAW 自动化也会更新同一组内部参数和 DSP。文件加载、浏览器、Help/About、焦点以及破坏性编辑操作不会作为自动化参数公开。

Sample Set 与 Slice

Alt+M 打开 Sample Set，每槽最多 16 个采样。Variation Mode 增加 Shuffle No Repeat：每轮以随机顺序播放全部符合条件的采样一次，相邻两轮之间也不重复相同采样。Tab 在列表和网格之间切换；Enter 加载，Delete 删除，Space 试听。Alt+E 打开 Slice Edit。F1/F2/F3 选择可用页面；Tab 切换页面，Alt+方向键编辑，Space 控制试听。Escape 关闭编辑器。

Help

LSampler-24 0.99.11：アクセシブルガイド

LSampler-24 は24スロットのサンプラーです。各スロットには1つのサンプル、または最大16サンプルの Sample Set を入れられます。メイン画面、パラメーターグリッド、ブラウザー、Slice Editor はキーボードとスクリーンリーダー向けに設計されています。

メインスロットページ

矢印キーで24スロットを移動します。Ctrl+Home/Ctrl+End は最初/最後のスロットへ移動します。Enter はパラメーター、Alt+Enter は Properties を開きます。Alt+R は名前変更、Alt+C はコピー、Alt+X はカット、Alt+V は貼り付けです。Delete は現在のスロット、Alt+Delete はバンクを消去します。Alt+P はスロット試聴を切り替えます。

主なボタンは Load Sample、Load Slot、Save Slot、Load Bank、Save Bank、Help、About です。Tab/Shift+Tab でフォーカスを移動します。ボタンにフォーカスがある間、矢印、Home、End、Page Up、Page Down はプラグイン内で消費され、外へ抜けません。Alt+L は現在のスロットへ戻り、Alt+H はヘルプ言語メニュー、Alt+A は About を開きます。

パラメーター

Enter でグリッドを開きます。矢印で移動、Alt+Shift+左/右でカテゴリ変更、Alt+上/下で値変更、Alt+Page Up/Down で粗い変更、Alt+左/右でステップ幅選択、Alt+Home/End で最大/最小へ移動します。Alt+V は Value、Escape はスロット画面へ戻ります。Ctrl+左/右は Sample Play Start を移動します。Alt+L はメインループ、Alt+G は Global を切り替えます。

DAW オートメーション

0.99.11 では、オートメーション可能な音楽/DSP コントロールを 6,629 個の独立した VST3 パラメーターとしてホストへ公開します。各パラメーターは “Slot 1 - Volume” や “Slot 2 - Filter Cutoff” のように実際のスロットと機能へ直接対応し、UI で現在選択しているスロットには依存しません。Grid/Value からの変更はホストへ通知され、DAW のオートメーションも同じ内部パラメーターと DSP を更新します。ファイル読み込み、ブラウザー、Help/About、フォーカス、破壊的編集操作はオートメーションパラメーターとして公開されません。

Sample Set と Slice

Alt+M で Sample Set を開き、1スロット最大16サンプルを扱えます。Variation Mode に Shuffle No Repeat を追加しました。対象サンプルを各サイクルでランダム順に1回ずつ再生し、サイクルの境界でも同じサンプルを連続再生しません。Tab はリストとグリッドを切り替え、Enter は読み込み、Delete は削除、Space は試聴です。Alt+E は Slice Edit を開きます。F1/F2/F3 で利用可能なページを選び、Tab でページ移動、Alt+矢印で編集、Space で試聴します。Escape で閉じます。

Help

Alt+H または Help ボタンで “Choose Help language” を開きます。内蔵ガイドは HTML として既定ブラウザーで開きます。
