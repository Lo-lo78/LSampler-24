# LSampler-24 0.99.23 — TEST164

Release date: 4 November 2026.

## Highlights

- Incremental, case-insensitive keyboard search by the displayed parameter names: type consecutive letters to refine the prefix.
- Repeat a single character to cycle forward, or hold Shift to search backward.
- Shift+digit searches the **digit** backward (Shift+1 means 1, not !). The historical `0` shortcut for Zero Crossing is preserved.
- Searches cover Slot/Global Grid, Bank Macro, Slice Editor parameter pages, FX Grid, and Sample Set F2.
- Prefix resets after 1.2 seconds, navigation commands, page changes, or focus changes.
- Updated accessible HTML Help (eight languages), About panel, version and release metadata.
- Preserves TEST163 per-slot MIDI Channel (Omni / 1–16), previous automation IDs, presets, DSP and audio behavior.
- Includes static regression gates and standalone C++ search tests; Windows VST3 builds with GitHub Actions after the original audio-parity TEST62 gate.

The VST3 build is generated by the GitHub Actions artifact `LSampler-24-Windows-VST3-TEST164`. Verify the final build with REAPER/NVDA before publishing the release.
