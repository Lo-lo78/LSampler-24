LSampler-24 TEST4
=================

Goal
----
Keep the TEST3 24-slot architecture and correct the sample root calibration before the first compile.

Key mapping
-----------
- 24 real slots.
- Every new Slot 1..24 starts open across the full MIDI range: Low Key 0, High Key 127.
- Every new slot factory Original Pitch is MIDI 60 (C4).
- Original Pitch is independent from Low Key / High Key.
- MIDI playback transposes relative to Original Pitch.
- Existing saved presets/states retain an explicitly stored Original Pitch.

Slot parameter order
--------------------
1. Low Key
2. High Key
3. Original Pitch
4. Voice Mode: Mono / Poly
5. Mono Mode: Trigger / Legato
6. Volume

Polyphony
---------
- 96 voices total per instance.
- Dynamically shared across all 24 slots.
- Mono uses one active voice per slot.
- Poly uses the shared pool.

Accessibility / navigation
--------------------------
- 3 columns x 8 rows, numbered vertically as in LBPMCaptureSample.
- Enter opens current slot parameters.
- Escape returns to the same slot.
- Alt+L Slots.
- Alt+O Load Sample.
- Alt+S Load Slot.
- Alt+Shift+S Save Slot.
- Alt+B Load Bank.
- Alt+Shift+B Save Bank.

Note speech/display
-------------------
Use LBPMCaptureSample form: MIDI number + note name + octave, e.g. `60 C 4`.
